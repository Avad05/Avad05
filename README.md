# Avadhut Kaskar

Software Developer based in Mumbai, India. Final-year Computer Engineering undergrad, currently interning at [Equifiz](https://equifiz.com) on a production fintech platform for Indian equities.

## Now

**Software Developer Intern, Equifiz** · Next.js, TypeScript, PostgreSQL

- **Fiz Quest:** built the hub for the paper-trading game: private lobbies of up to 50 players and 1v1 duels, live standings, trading only during market hours, and a daily job after the 3:30 PM close that locks in final prices and ranks.
- **Referrals:** invite links and codes that give both people bonus virtual cash, with one code per account.
- **Scale:** per-user rate limits and batched settlement, load-tested with 5,000 players and 13k contests (room loads ~20 ms).
- **Fiz AI:** UI work on the platform's AI research assistant.

## What I've Built

- **PR Synthesizer:** Multi-agent AI code review system using the A2A protocol (JSON-RPC 2.0), RAG with pgvector, BullMQ, and Docker Compose across Node.js and Python microservices.
- **Legal RAG API:** Agentic Q&A API for legal documents built with LangGraph, FastAPI, and Pinecone. A two-stage quality gate keeps it from giving made-up answers.
- **Peer Demo Showcase (Lamatic AgentKit):** Open-source kit contribution that crawls GitHub repos and matches builders to sponsors using automated reasoning. [PR #295](https://github.com/Lamatic/AgentKit/pull/295)
- **Emergency Response Coordination System:** Real-time emergency dispatch platform with priority-based unit allocation and live incident tracking.
- **Blog-API:** Full-stack blogging platform with JWT auth and Prisma ORM, deployed on Cloudflare Pages.
- Open source contributor to **Odysseus** ([PR #4043](https://github.com/odysseus-dev/odysseus/pull/4043)): backend timing fix on a large active codebase.
