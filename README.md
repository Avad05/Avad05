# Avadhut Kaskar

Software Developer based in Mumbai, India. Final-year Computer Engineering undergrad building production-grade backend systems and AI infrastructure.

## What I've Built

- **PR Synthesizer** — Multi-agent AI code review system using the A2A protocol (JSON-RPC 2.0), RAG with pgvector, BullMQ, and Docker Compose across Node.js and Python microservices.
- **Legal RAG API** — Agentic Q&A API for legal documents built with LangGraph, FastAPI, and Pinecone, featuring a two-stage quality gate to eliminate hallucinated answers.
- **Peer Demo Showcase (Lamatic AgentKit)** — Open-source kit contribution that crawls GitHub repos and matches builders to sponsors using automated reasoning. [PR #295](https://github.com/Lamatic/AgentKit/pull/295)
- **Emergency Response Coordination System** — Real-time emergency dispatch platform with priority-based unit allocation and live incident tracking.
- **Blog-API** — Full-stack blogging platform with JWT auth and Prisma ORM, deployed on Cloudflare Pages.
- Open source contributor to **Odysseus** ([PR #4043](https://github.com/odysseus-dev/odysseus/issues/4045)) — backend timing fix on a large active codebase.

## Current Stack

- **Backend:** Node.js, Express, Python, FastAPI
- **Databases:** PostgreSQL, pgvector, Redis, Supabase, Pinecone
- **AI:** Gemini API, OpenRouter, RAG pipelines, LangGraph, Vector Embeddings, A2A Protocol
- **Infrastructure:** Docker, Docker Compose, Linux (Arch)
